# Настройки агента

Все файлы этой папки можно редактировать в обычном текстовом редакторе. Не меняйте названия полей слева от `=`.

- `agent.toml` — параметры расчёта, гарантия, срок изготовления и частота проверки папки `input`.
- `qwen.toml` — параметры локальной Ollama/Qwen. Обычно менять их не требуется.
- `competitors.toml` — компании-конкуренты и подтверждённые аналоги тканей. Это основной файл для ручного пополнения базы знаний.
- `competitor_sources.toml` — сайты и каталоги, которые агент может учитывать как справочный источник. Они не являются источником нашей цены.

## Как добавить аналог ткани

1. Откройте `competitors.toml`.
2. Скопируйте закомментированный пример `[[analogue]]` в конце файла.
3. Заполните название ткани конкурента, точную ткань из нашего прайса, категорию и допустимую систему.
4. До проверки оставьте `verified = false`. Агент такую запись проигнорирует.
5. После подтверждения специалистом замените на `verified = true`. При следующей обработке ТЗ агент сможет использовать этот аналог автоматически.

Допустимые категории: `E`, `1`, `2`, `3`, `4`, `5`.
