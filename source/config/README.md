# Конфигурация

- `agent.toml` — параметры расчёта и цикла наблюдения. Здесь же меняются `warranty_text` и `production_days`, которые выводятся в КП. Скидка, монтаж и доставка пока отключены и в конфиг не входят.
- `qwen.toml` — только параметры локальной модели Ollama/Qwen.

Формат TOML выбран вместо JSON, потому что TOML поддерживает комментарии. PDF формируется кодом и отдельной настройки шаблона не требует.
