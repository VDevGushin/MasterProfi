# База знаний конкурентов

Файл `competitors.yaml` — ручная, долговременная база знаний агента.

Добавляйте запись в `analogs`, когда подтверждён аналог ткани конкурента. После следующего запуска агент загрузит её в локальную базу и сможет автоматически использовать категорию ткани для расчёта.

Пример:

```yaml
- competitor: "gamma_i"
  source_material: "Карина Int"
  local_fabric: "Омега светло-голубой"
  category: "1"
  system: "Стандарт MG"
  confidence: 1.0
  verified: true
  source_url: "https://gamma-i.ru/..."
```

Пока `verified` равно `false` или поле отсутствует, агент не использует запись для цены.
